*Table 3-3. Operator Level Troubleshooting*

<table>
<tr><th>MALFUNCTION</th><th>TEST OR INSPECTION</th><th>CORRECTIVE ACTION</th></tr>
<tr><td rowspan="6">1. ENGINE WILL NOT CRANK</td><td>a Check that EMERGENCY STOP switch is not engaged.</td><td>Pull out switch to disengage.</td></tr>
<tr><td>b. Check that START / RUN / STOP switch is in START position.</td><td>Place switch in START position.</td></tr>
<tr><td>c. Check if DC CIRCUIT BREAKER is tripped.</td><td>Reset by depressing pushbutton.</td></tr>
<tr><td>d. Check malfunction indicator module for system fault light.</td><td>Refer to applicable troubleshooting procedure for fault condition.</td></tr>
<tr><td>e. Check battery wires for proper / secure connection.</td><td>Tighten connections.</td></tr>
<tr><td>f. Refer trouble to unit level maintenance.</td><td></td></tr>
<tr><td rowspan="6">2. ENGINE CRANKS BUT WILL NOT START</td><td>a. Check if PREHEAT switch was actuated for cold weather operation.</td><td>Place switch in proper position.</td></tr>
<tr><td>b. Check that mechanical governor speed control knob is in START position and tightened.</td><td>Adjust control knob and tighten (see item 6, Figure 2-4).</td></tr>
<tr><td>c. With the START/RUN/STOP switch in the RUN position, ensure Governor Actuator Lever (see item 1) is releasing from magnet.</td><td>If not, refer trouble to unit level maintenance.</td></tr>
<tr><td>d. Check fuel tank level (refer to para. 3-7).</td><td>Service fuel tank as required. Press FAULT RESET pushbutton to reset fault indicator module.</td></tr>
<tr><td>e. If operating on AUX FUEL, check that AUX FUEL switch is in ON position.</td><td>Place switch in ON position. Press FAULT RESET pushbutton to reset fault indicator module.</td></tr>
<tr><td>f. Inspect for crimped or pinched fuel lines.</td><td>Straighten flexible fuel lines. Refer to unit level maintenance if fuel line is damaged.</td></tr>
</table>
