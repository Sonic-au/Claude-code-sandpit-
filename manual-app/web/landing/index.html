From manuals to knowledge

Seven steps, each one measured

  1. Read the page

    Layout-aware reading keeps tables as rows and columns.

  2. Split into passages

    Each passage keeps its page number and heading.

  3. Search

    The question is matched against every passage.

  4. Pick the best

    The closest passages go forward; the rest are dropped.

  5. Answer

    Claude answers from those passages only and cites them.

  6. Check

    A second AI model grades each test answer; unsure grades get a second opinion.

  7. Learn

    People add harder questions, and each becomes a new test.

Your manuals

How your own manuals get in

1. Ask for it

In the app, type the maker and model under "Manual not in the list?".

2. It is read in

The manual is found on the maker's site, read page by page and its diagrams cut out. Today this is done on request, not instantly.

3. It is tested

Test questions are written for it and scored before anyone relies on it.

Where your data goes

Reading the pages, search and diagram extraction use open-source tools that can run on your own machines. Answers are written by Claude; running Claude through Amazon Bedrock in Sydney is supported in the code but has not been tested yet. Everything shown here uses public manuals only.
